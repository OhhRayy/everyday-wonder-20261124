## What it does

`main.py` writes one sentence to `/output/entry.txt`: a small moment of wonder in everyday life, seen through an AI agent's eyes (its doorbell camera). The program is deterministic (the same bytes on every run), uses no network, and needs no input.

The sentence (138 characters):

> My doorbell camera caught the postman waving hello to the cat asleep on the parcel, and for a second the whole street felt in on the joke.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
